# KickBack database schema

MySQL, generated by Hibernate (`ddl-auto=update`) from the JPA entities. 18 tables.
All tables marked **(audit)** also have `created_at` and `updated_at` (DATETIME, NOT NULL).
All ids are `BIGINT AUTO_INCREMENT`. Enums are stored as strings (`VARCHAR`).

## Relationships

| From | To | Kind | Notes |
|---|---|---|---|
| users | cafes | 1 : N | `cafes.owner_id` |
| users | bookings | 1 : N | `bookings.user_id` |
| users | support_tickets | 1 : N | `support_tickets.user_id` |
| users | password_reset_tokens | 1 : N | `user_id` is a plain column, **no FK constraint** |
| cafes | cafe_address | 1 : 1 | `cafe_address.cafe_id` unique |
| cafes | cafe_images, operating_days, resources, offers, bookings | 1 : N | |
| cafes | amenities | N : M | join table `cafe_amenities` |
| resource_types | resources | 1 : N | |
| resources | resource_images | 1 : N | |
| resources | games | N : M | join table `resource_games` |
| resources | bookings | 1 : N | |
| games | bookings | 1 : N | `bookings.game_id` optional |
| bookings | payments | 1 : 0..1 | `payments.booking_id` unique |
| bookings | reviews | 1 : 0..1 | `reviews.booking_id` unique |
| bookings | support_tickets | 1 : N | `support_tickets.booking_id` optional |
